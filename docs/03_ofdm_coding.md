# 03 · OFDM、编码与资源分配

## 1. 把一个高速流拆到许多正交子载波

一个 OFDM 符号中，每个激活子载波可以承载一个 QAM/PSK 符号。IFFT 把频域的点合成为时域序列：

```text
x[n] = (1/√N) Σ X[k] exp(j2πkn/N)
Δf = Fs/NFFT
Tu = 1/Δf
Tsymbol = (NFFT + NCP)/Fs
```

本项目使用乘 `sqrt(NFFT)` 的 IFFT 和除 `sqrt(NFFT)` 的 FFT，让单位变换能量关系容易检查。

OFDM 是多载波组织方式；QAM 是子载波上使用的调制。说“OFDM 和 64QAM 哪个好”并不是同一维度的比较。

## 2. 一个可以手算的默认例子

`NFFT=256`，`Δf=15 kHz`，`NCP=32`，200 个数据子载波，16QAM，无编码，无导频：

- Fs=3.84 MS/s。
- 有效符号时长 66.667 μs，CP 8.333 μs，总计 75 μs。
- 每个 OFDM 符号 200×4=800 bit。
- 理想数据率 800/75 μs≈10.667 Mbit/s。
- 这还不是 LTE/NR：没有标准导频、编码、帧结构、保留资源与控制信道。

## 3. CP 的作用与边界

CP 把符号尾部的一段复制到前面。在信道在一个符号内近似不变、定时合适且最大多径超时不超过 CP 的条件下，它把有效符号区间内的线性卷积变成循环卷积。FFT 后：`Y[k]=H[k]X[k]+W[k]`，每个子载波可独立均衡。

**CP 不会自动把 H[k] 变成 1。** lab04 即使 CP 足够，也用已知 H[k] 做一阶均衡；若你删去均衡，星座仍然会扭曲。CP 太短时出现符号间干扰与载波间干扰，再除 H[k] 也不能完全恢复。

实际系统还要考虑定时误差占用 CP 余量、信道时变、窗函数和滤波尾部。

## 4. 频偏为什么伤害 OFDM

频偏使符号内的相位连续旋转。若用 `ε=CFO/Δf` 表示归一化频偏，即使 CFO 的 Hz 数不大，只要接近子载波间隔的显著比例，就会破坏 FFT 正交性，造成 ICI。还可能产生每符号共同相位误差 CPE。

练习：基础 OFDM Δf=15 kHz，把 CFO 设为 150、1500、7500 Hz。分别记录 EVM。先只做 FFT；再思考为什么补偿一个固定相位不能完全消除 ICI。

## 5. DFT-s-OFDM

在子载波映射之前，对数据符号先做一个 DFT，接收端再做逆 DFT。数据能量被相关地铺在一组子载波上，时域形态更像单载波，通常具有较低 PAPR。

LTE 上行采用 SC-FDMA/DFT-s-OFDM；NR 上行可选择 CP-OFDM 或 DFT-s-OFDM。NR 下行采用 CP-OFDM。本项目 `nr_ul.TransformPrecoding=true` 控制这一选择；默认实验使用 48 个连续 PRB，以满足常见变换长度约束。具体合法配置仍由工具箱验证。[官方参数定义](https://www.mathworks.com/help/5g/ref/nrwavegenpuschconfig.html)

lab11 比较的是同一数据块、相同激活子载波与相同采样率下的教学波形。PAPR 的统计结论需要足够长的数据和过采样；一次结果不能当标准极限。

## 6. OFDMA、MIMO 与多用户

OFDMA 把子载波资源分给不同用户。Wi-Fi HE/EHT 使用 RU 描述资源分配；NR 使用 PRB/BWP 等配置。MIMO 则利用多个天线/空间层，同时传输或提高可靠性。这两种机制可以组合。

数据矩阵 `Nsamples × Nantennas` 的每一列是一条天线波形，**不是**某条波形的 I 和 Q。每列本身已经是复数。MIMO 导出一列一个文件，需要多路同采样时钟、同触发、可控相位的硬件才能保留其空间关系。

## 7. 编码、扰码、交织、CRC

| 处理 | 主要目的 | 能否直接纠错 |
|---|---|---|
| CRC/FCS | 检测帧/块是否被破坏 | 通常不能 |
| FEC | 加冗余，允许接收端纠错 | 可以，在能力范围内 |
| 交织 | 重新排列比特，使突发错误分散 | 本身不纠错 |
| 扰码/白化 | 改善比特统计分布、避免长串同值 | 不是加密，不负责纠错 |
| 加密/认证 | 保密、完整性和身份相关保护 | 不等于物理层纠错 |

LTE 和 NR 的不同信道使用不同编码；Wi-Fi 的 MCS 同时关联调制与码率。只修改星座阶数，不同步修改其他链路参数，可能不是任何合法 MCS。

不要把 BER、BLER、PER 混在一起：BER 针对比特；BLER 针对传输块解码；PER 针对包，包括检测/校验失败。高阶调制给出更多映射比特，但在低 SNR 下可能使有效吞吐下降。

## 8. NR 数字参数关系

典型 numerology 中 `Δf=15×2^μ kHz`。正常 CP 下，一个 slot 有 14 个 OFDM 符号；slot 时长约 `1/2^μ ms`。一个 PRB 有 12 个子载波。20 MHz 信道并不意味着所有 20 MHz 都承载 PRB；边缘留有保护带。

本项目 NR 默认 20 MHz / 30 kHz / 51 PRB，名义资源跨度 51×12×30 kHz=18.36 MHz；生成器返回的采样率由 FFT 和实现选项决定，应读取结果，而非设为 20 MHz。
