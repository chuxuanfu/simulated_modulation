01 · IQ、采样和通信链路

1. 比特不会直接变成天线上的正弦波

发射链路可以写成：

应用字节 → 包头/CRC → 信道编码 → 交织/扰码 → 调制映射
        → 脉冲成形 或 资源格+IFFT+CP → 复数 IQ → DAC/上变频 → RF

接收链路反过来，但还需要包检测、自动增益、定时、频偏补偿、信道估计与均衡。发射端知道的时间和参数，真实接收端往往不知道。

调制决定信息如何改变幅度、相位或频率；编码加入冗余以对抗错误；帧结构使接收机知道何时开始、用什么格式以及载荷多长。三者各有作用。

2. 复数基带到底是什么

定义 x(t)=I(t)+jQ(t)。本项目采用：

s_RF(t) = Re{x(t) exp(j 2π fc t)}
        = I(t) cos(2π fc t) − Q(t) sin(2π fc t)

I 和 Q 是同一信号的两个正交坐标，不是两种互不相关的射频信号。abs(x) 是包络；angle(x) 是相位。采样后的文件只存 x[n]，通常不直接存几 GHz 的真实 RF 正弦波。

例如：Wi-Fi 中心频率设为 2.412 GHz，基带采样率可以是 20 MS/s。仪器以本振把基带搬到 RF；MATLAB 不必以大于 4.824 GS/s 的速率采样实数 RF。

CenterFrequencyHz 在本项目通常是元数据/仪器设置意图，不会自动给基带乘 2.412 GHz 的复指数。数字频移应使用相对于基带的偏移量，例如 +1 MHz。

3. bit、symbol、chip、sample

名称 含义 常见误区
bit 0/1 信息或编码结果 净载荷比特率不一定等于空口比特率
symbol 一次调制选择 16QAM 每个符号承载 4 个映射比特
chip 扩频码片 一个信息符号可以扩展成很多码片
sample 波形离散采样点 8 sample/symbol 并非每符号 8 个信息比特

未编码单载波中：Rb=Rs log2(M)，Fs=Rs*SPS。有编码时净信息速率还乘码率；有前导、导频、CP、空闲和重传时，应用吞吐量更低。OFDM 则同时有很多子载波，不能直接把总比特率代入单载波公式。

计算练习：16QAM，Rs=1 Msym/s，SPS=8，码率 1/2。采样率 8 MS/s，映射比特率 4 Mbit/s，忽略其他开销的净速率约 2 Mbit/s。

4. 采样与混叠

复数采样频率 Fs 对应一个宽度 Fs 的频率区间，常画成 [-Fs/2,Fs/2)。为了留出滤波过渡带，实际信号通常不能塞满整个区间。

exp(j 2π f n/Fs) 与 exp(j 2π (f+Fs) n/Fs) 相同。lab01_iq_sampling 用这个恒等式让你亲眼看到混叠。采样率写错不会改变文件的数值，却会让时间尺度与频率轴一起错误。

对于数字搬移，必须满足信号搬移后的高低频边界仍在 Nyquist 区间内。仅检查 abs(fOffset)<Fs/2 不够，还要把信号带宽算进去。

5. FFT 的几个约定

  • MATLAB FFT 输出默认把 DC 放在第一个元素；绘图用 fftshift 将 DC 移到中央。
  • 教学 OFDM 的资源格采用中央 DC 排序，所以 IFFT 前需要 ifftshift。
  • +125 kHz 复指数应在 +125 kHz 出现峰。把 Q 取反相当于共轭，会使频谱镜像。
  • FFT 点数增大或补零会让曲线更密；真正的分辨能力仍受有效观测时间和窗函数限制。

6. 功率与单位

本项目中 IQ 是无量纲幅度。mean(abs(x).^2) 是数字域平均功率，sqrt(...) 是 RMS。dB 是比值：功率比用 10 log10，幅度比用 20 log10。

0 dBFS、0 dBm、IQ 峰值 1 不是同一个概念。 dBm 对应实际毫瓦，取决于仪器输出标定、阻抗、增益与线缆损耗。不能从无量纲 IQ 单独推断 dBm。

例：把 IQ 乘 0.5，数字平均功率变成原来的 1/4，即 −6.02 dB；但仪器如果自动归一化再以指定平均功率输出，实际端口功率不一定随之减 6.02 dB。必须理解设备的 ARB 电平定义。

7. 随机不等于不可复现

Seed 决定载荷随机序列；项目生成器保留并恢复调用前的 MATLAB 随机状态。相同参数、种子、MATLAB/工具箱版本应产生可重复结果。跨版本算法默认值可能变化，因此实验应保存实际 IQ 和 waveform.mat，不能只保存一个种子。
