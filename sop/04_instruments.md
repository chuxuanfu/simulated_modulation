# SOP-04 · 从 IQ 文件到实验仪器

本 SOP 采用“先离线核对，再有线/屏蔽连接”的实验路径。由于尚未指定设备型号，项目提供通用 IQ 与字段对应，不猜测厂商二进制头或 SCPI 命令。具体导入界面和幅度定义以设备手册为准。

## 0. 先填设备能力表

| 字段 | 要填写的值 |
|---|---|
| 信号源/SDR 型号、固件 | 待填 |
| 支持的 ARB 采样率/插值倍率 | 待填 |
| 最大模拟/IQ 带宽 | 待填 |
| 支持的输入格式与端序 | float32/int16/厂商格式 |
| IQ 顺序与 Q 符号约定 | 待填 |
| 波形长度粒度与最小长度 | 待填 |
| 可用存储、通道数 | 待填 |
| 电平是平均还是峰值、是否自动归一化 | 待填 |
| 接收仪器最大输入电平 | 待填 |
| 线缆与衰减器总损耗 | 待填 |
| 触发/参考时钟/多路相位同步 | 待填 |

## 1. 离线核对

1. 运行对应协议生成器，保留完整输出包。
2. 用 `sm.readIQ` 读回 float 或 int16；比较点数与误差。
3. 根据 manifest 确认 Fs，而非凭带宽猜 Fs。
4. 按设备所需粒度处理长度。对于包型波形可在包后补零并记录；不要裁掉包头、CRC 或脉冲尾部。
5. 如果设备只接受特定采样率，用 `sm.resampleWaveform` 进行滤波重采样，再重新导出与检查。若接近带宽边界，先确认滤波没有损害信号。

## 2. 文件格式对应

| 设备导入项 | 本项目取值 |
|---|---|
| Data layout | Interleaved I,Q；每路单独文件 |
| Number type | Float32 或 signed Int16 |
| Byte order | Little endian |
| Header | None；SigMF 元数据在另一个 JSON 文件 |
| Float scaling | 原始 IQ 乘 manifest.ExportGain |
| Int16 scaling | round(floatIQ*32767)，读回除以 32767 |
| Sample rate | manifest.SampleRateHz |
| RF center | manifest.CenterFrequencyHz，需手动设置仪器 |
| Channels | manifest.NumChannels；不把两路天线当 I/Q 两列 |

如果设备不接受 `.sigmf-data` 扩展名但接受裸 float32，可复制成 `.bin` 后在设备上手动选择格式；改扩展名不会改变文件内容。需要厂商专用格式时，用厂商导入工具封装，不凭空写一个看似正确的头。

## 3. 用单音先确认链路

先生成 +100 kHz 或 +125 kHz 复单音并低电平导入，确认接收谱线出现在本振上方。如果在下方，检查 Q 符号或 IQ 顺序。先把这个问题解决，再导入复杂协议。

推荐 MATLAB 构造：

```matlab
fs = 1e6;
x = 0.5*exp(1i*2*pi*125e3*(0:8191).'/fs);
p = struct('Protocol','calibration_tone','Seed',0,'CenterFrequencyHz',2.4e9);
w = sm.pack(x,fs,p,'Single tone for IQ sign/sample-rate verification');
folder = tempname(fullfile(sm.root(),'generated'));
sm.exportBundle(w,folder,0.8);
```

本例输出仍会按统一峰值缩放；实际 RF 电平由信号源设置和测量。

## 4. 硬件连接与电平

先保持 RF 输出关闭。按接收机输入能力配置衰减，以有线或屏蔽环境完成初次验证；核对连接器、50Ω 负载和设备输入限值。RF 输出电平、外部增益与损耗应记录，不从数字峰值推算接收端安全电平。

例如希望接收端 −40 dBm、链路总损耗 30 dB，在忽略其他增益时源端平均输出应约 −10 dBm；但必须核对设备对“平均”的定义和实际功率读数。多载波峰值高于平均值，还要给峰值留余量。

## 5. 载入协议波形

1. 关闭源端自动改写采样率/幅度的功能，或记录其实际行为。
2. 设置 RF 中心频率与 ARB Fs；选择单次/循环播放模式。
3. 配置接收端跨度、采样率、触发和捕获时长。至少覆盖一个完整包和其前后余量。
4. 从低电平开始输出，观察单音/波形；确认无过载后调整至目标接收功率。
5. 核对包周期、时长、谱宽、中心频率。
6. 使用对应解调器配置已知 PHY、带宽、MCS 等，测 EVM/BER/PER。
7. 保存接收 IQ、仪器设置和屏幕结果到该实验记录。

## 6. 循环与突发

BLE/Thread 的导出包括指定空闲，但经典蓝牙包时序由工具箱决定；不要统一假设所有文件都有相同间隔。连续循环可能在文件首尾产生不连续：优先完整包+空闲，检查循环边界。如果研究连续流则应设计相位与滤波状态连续的发生方式。

## 7. SDR 与 SCPI 的后续接入

SDR 常要求特定支持包、插值倍率、帧长度和数据类型；VSG 常要求厂商 ARB 格式或专用上传 API。取得确切设备型号后，可把本项目输出接到相应驱动。当前版本没有未经设备验证的“万能发射脚本”，也不自动执行 RF ON。

## 验收与停点

只有当格式、频率方向、采样率、时长、电平和接收判据全部核对后，才进入目标实验。若格式不支持或硬件带宽不足，停在文件准备阶段，选择兼容采样率/格式或降低实验带宽；不靠改元数据绕过限制。
