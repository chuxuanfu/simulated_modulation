# 实验记录模板

## 基本信息

- 实验编号 / 日期 / 操作者：
- 目标问题与运行前预测：
- 项目版本 / 源码哈希：
- MATLAB / 工具箱 / 操作系统：
- 使用脚本或 JSON：
- 原始波形目录 / 接收数据目录：

## 信号配置

- 协议 / PHY / 上下行 / 包类型：
- 调制 / MCS / 码率：
- 采样率 / 符号率或 SCS / 带宽 / PRB或RU：
- 载荷长度 / 包数 / 空闲 / 时长 / 通道数：
- 中心频率意图 / 数字频偏：
- 种子 / CRC与MAC有效性 / Scope：
- 导出格式 / IQ顺序 / 端序 / ExportGain：

## 仪器与链路

- 信号源 / 接收机 / 固件：
- ARB Fs / 时钟与触发 / 自动归一化：
- 源端电平及定义 / 衰减 / 线损 / 接收功率：
- 捕获设置 / 解调设置 / 同步与均衡方式：

## 验证

- 核心测试：PASS / FAIL / 未运行
- 目标协议测试：PASS / FAIL / SKIP / 未运行
- 格式读回与字节数：
- 包长度 / CRC / 已知数据恢复：
- 实际 EVM / BER或PER / PAPR / OBW及测量口径：
- 统计样本量 / 错误数 / 置信范围：

## 观察与结论

- 图像和数据文件位置：
- 与预测一致之处：
- 不一致之处及可能原因：
- 结论适用范围：
- 尚未验证内容：
- 下一步只改变的一个因素：
